# 港股报价

给“持仓提醒”里登记的港股（代码写成 `00981.HK`）补上名称、现价、涨跌和港元兑人民币汇率。
只用来展示持仓，不参与选股、回测和监控提醒。

- 数据来源：新浪财经公开接口，一次请求问回所有要的港股和汇率，经过免费数据源的限流器。
- 更新：跟着面板的“实时行情”开关和“每隔多少秒取一轮全市场快照”的设置，和期货一致。
- 开关关着时：不跟着盘中变。只在存着的数据早于最近一次港股收盘、或有刚登记还没取到过的股票时取一次。
- 汇率是市场中间价，和券商港股通的结算汇率会差一点，折算出来的人民币市值是参考数。
- 取到的数据存在 `data/user_data/extensions/hk_quotes/quotes.json`。
