# 复盘信号

每天收盘后的复盘生成好以后，把“持仓复盘”一节里写明的价位（防守线、止损位、突破位）变成监控中心的价格提醒，
只管**下一个交易日**。那个交易日走完就自动删掉；有了新的复盘就换成新的一批。监控中心里永远只有最新一份复盘的信号。

## 怎么生成

1. 每分钟检查一次：行情最新那一天有没有“收盘后生成”的复盘，而且还没为它生成过信号。
2. 把“持仓复盘”一节交给面板里配置的 AI，只让它**摘录**原文里写了数字的价位和对应做法，不让它自己判断。
3. 每一条都要核对，过不了的丢掉：
   - 必须是持仓提醒里登记的 A 股或 ETF（港股不在监控范围内）；
   - 价位必须原样出现在这只股票自己的那段复盘里；
   - 收盘时已经跌破/突破的不建；
   - 离收盘价超过一个涨跌停板、下一个交易日到不了的不建。
4. 写成监控规则（id 以 `rs_` 开头，名字以“复盘信号 ·”开头），推送渠道用“新建规则默认渠道”。

AI 调不通或回复读不懂时，旧信号保持不动，同一份复盘最多试 3 次。

## 什么时候删

- 复盘之后的下一个交易日收盘、当天行情进到面板以后（不靠日历，所以周末和节假日不会误删）；
- 有了更新的复盘（包括同一天手动重新生成的复盘）时整批替换；
- 行情一直没有更新时，复盘过去 10 天兜底作废；
- 在设置里关掉时立即清除。

本扩展只增删 `rs_` 开头的规则，别的规则不碰。

## 接口

- `GET /api/custom/recap-signals/status`：当前这批信号、没采用的价位和原因
- `POST /api/custom/recap-signals/run`：按最新的收盘后复盘重新生成（调用一次 AI）
- `PUT /api/custom/recap-signals/options`：`{"enabled": true|false}`

状态存在 `data/user_data/extensions/recap_signals/`，属于个人数据，不进仓库。

## 注意

和其他监控规则一样，只有打开实时行情时才会触发。规则按盘中价格判断；复盘里写“收盘跌破”的，提醒文字里会保留这句话，
盘中触发后是否操作以收盘为准。
