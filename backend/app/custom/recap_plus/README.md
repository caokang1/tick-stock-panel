# 复盘补充数据（recap_plus）

面板自带的 AI 复盘只把指数、涨跌家数、板块排名交给 AI。这个扩展在后面再接一段材料，让复盘可以写到榜单、
行业涨跌停、两融和自己的持仓。复盘页、定时复盘、归档、推送都还是面板原来的，这里只管“多给 AI 一些数据”。

## 多给了哪些数据

| 内容 | 来源 |
|---|---|
| 沪、深成交额及较前一日的变化 | 本机日线 |
| 成交额前十、总市值前十 | 本机日线、股票资料里的总股本 |
| 各行业的涨停、跌停家数和代表股票 | 本机日线、行业归属表（东方财富行业，不是申万一级） |
| 全市场两融（融资余额、融资买入额等） | 东方财富数据接口，联网 |
| 每只持仓的数量、成本、盈亏、近 5/10/20 日表现 | “持仓提醒”里登记的持仓、本机日线 |
| 每只持仓的市盈率、市净率、市值 | 腾讯行情接口，联网 |
| 每只持仓的主力资金流向、两融 | 东方财富，联网 |
| 对标股票当天的涨跌 | 本机日线 |

哪一块没有取到，材料里会明说，并要求 AI 写“未取得”，不要编。

## 联网的规矩

- 每个请求都经过限流器（记在东方财富、腾讯行情两个来源名下），一个一个发，不并发。
- 东方财富有一个请求没成，后面发往它的请求就不再发，也不重试、不换别的入口。
- 一次复盘大约发 `1 + 持仓数 × 2 + 1` 个请求（8 只持仓约 18 个）；资金流向最多取 12 只。
- 同一个交易日取到的结果存在 `data/user_data/extensions/recap_plus/cache/`，当天重跑复盘不重复请求。

## 手动复盘和定时复盘怎么配合（`sync.py`）

- **手动点“开始复盘”，随时都给当天的**：今天开过市、而面板里还没有今天的行情时（正式日线 17:30 才有），
  先让面板按实时行情取一次当天的快照，再生成。判断“今天开没开市”只发一个行情请求（经限流器）。
  只在日 K 用的是“免费公开来源”时这样做；取不到就照旧用手头最新的数据。
- **手动跑过，定时的就不跑**：定时复盘开跑前看一眼，最新这一天的复盘在当天 15:00 收盘以后已经生成过，就跳过。
  盘中生成的不算（那时当天的行情还没走完）；复盘的是前一天数据的也不算。

## 设置

- **持仓**：在面板的“持仓提醒”页登记，这里直接读。
- **对标股票**：`data/user_data/extensions/recap_plus/config.json`，例如
  `{"peers": {"000001.SZ": ["600000.SH", "600036.SH"]}}`。目前没有页面，要手改这个文件。
- **复盘写成什么样**：由复盘页里的“提示词”决定（面板原有功能）。要让 AI 写持仓、给操作建议，需要在提示词里写明。

`GET /api/custom/recap-plus/preview` 可以看到会交给 AI 的这段材料原文。

## “每日复盘”页

左侧菜单的“每日复盘”是另一种看复盘的方式（前端在 `frontend/src/custom/recap-plus/`）：

- **首页·市场全景**：当天的指标卡（上证、成交额、涨停跌停、涨跌家数、两融余额、融资净买入）、
  最新一份报告里的“市场全景”一节、近 15 个交易日的四张走势图（上证收盘、成交额、涨停跌停家数、两融余额），
  以及报告里的“数据质量自查”一节。
- **每日复盘·归档**：按日期切换，看每天存档的复盘全文；同一天生成过几次的只显示最后一次。

走势按本机日线现算（`GET /api/custom/recap-plus/dashboard`），两融序列每天联网取一次。
报告用的是面板“复盘”功能的存档，所以要先有存档（手动保存或定时复盘），这里才有内容。

## 看板上的“持仓公告”

看板（首页）监控中心上方有一个“持仓公告”小组件：持仓股票近三天的上市公司正式公告，点标题打开公告原文，
上一个交易日收盘之后挂出来的标“新”。公告来自东方财富的公告列表，全部持仓一次请求取完，半小时内不重复取
（`GET /api/custom/recap-plus/notices?days=3`）。复盘材料里也会带上近几天的公告标题（只有标题，没有正文）。

## 对面板核心文件的改动

看板的组件登记表（`frontend/src/components/dashboard/registry.tsx`、`layout.ts`）里加了“持仓公告”这一项，
默认布局里把它放在监控中心上方。自己调过看板布局的，需要在“自定义布局”里手动把它加进来。


`backend/app/services/market_recap.py` 加了一个入口：拼材料时如果装了这个扩展，就把它返回的文字接在后面。
没装或者出错时为空，原来的复盘不受影响。
