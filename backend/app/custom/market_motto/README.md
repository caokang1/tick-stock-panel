# 左上角的话

侧栏左上角那句话按市场情绪评分自动换。

## 怎么挑

- 评分用面板自己算的情绪评分（0 到 100），和每日复盘、看板上的是同一个数。实时行情开着时是盘中的，关着时是最近一个交易日收盘的。
- 语料库按分数分档，评分落在哪一档，就从那一档里挑一句。
- 同一天同一档固定是同一句，第二天换；盘中评分跨到另一档时，话跟着换。
- 评分算不出来、或者评分落在没有话的地方时，显示默认那句。

## 语料库

一个纯文本文件：`data/user_data/extensions/market_motto/corpus.txt`（在个人数据目录里，不进代码仓库）。
可以直接用记事本改，也可以在“设置 → 左上角的话”里改，保存后马上生效。文件不存在时用代码里自带的示例。

```
# 井号开头的是备注
冰点（0-30）
现金也是仓位
少看盘，多复盘

偏冷（30-45）
轻仓试错，错了就走
```

- 档位写成“名称（下限-上限）”，评分满足 下限 ≤ 评分 < 上限 时用这一档；上限写 100 时含 100。
- 档位的个数、名称和分数线都可以改，范围不能重叠。
- 每句最好不超过 14 个字，再长在侧栏里显示不全。

## 接口

- `GET /api/custom/market-motto/current` 现在该显示哪一句
- `GET / PUT / DELETE /api/custom/market-motto/corpus` 读、存、恢复自带的语料库
