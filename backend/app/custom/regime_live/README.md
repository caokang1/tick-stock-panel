# 市场环境盘中刷新

面板原本只在收盘后的管道里计算“市场环境”，盘中页面停在上一个交易日。这个扩展让它跟着实时行情走。

## 怎么工作

1. “设置 → 实时监控 → 页面实时刷新”里多了一项“市场环境”（默认开）。
2. 市场环境页面开着、实时行情也开着时，每来一轮新行情，页面会调一次
   `POST /api/custom/regime-live/refresh`。
3. 接口用面板自带的增量计算，把行情文件比结果新的日子（盘中就是今天）重算一遍；
   算出了新结果，页面上的各块数据自动重新读取。

## 限制和保护

- 两次重算至少间隔 30 秒；同一时间只算一次；收盘后的管道或数据修复在跑时不算。
- 只重算“市场环境”这张表。它自带“行情比结果新就重算”的判断，收盘后的管道会用收盘数据再覆盖一次，
  盘中的临时结果不会留下来。
- **概念/行业主线不在盘中更新**：那张表当天算过就不会再算，盘中写进去会把临时结果留到收盘以后。
  所以“情绪周期”里的主线仍然是收盘后才更新。
- 页面没开着、开关关掉、或实时行情没开时，不会有任何请求。
