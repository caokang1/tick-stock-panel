# 每日汇总（daily_digest）

每个交易日的定时任务都跑完以后，把“每日复盘 + 系统快照”做成一个网页，并把摘要、复盘全文和网页链接用一张卡片推到飞书。

## 什么时候发

每分钟检查一次，同一天只发一次：

- 面板里的行情已经是今天的（休市日不发），并且没有正在跑的同步任务；
- 开了“定时复盘”：到了复盘的时间，且今天收盘后的复盘已经生成，就发；到点后等了 45 分钟还没有复盘，只发系统快照，并在卡片里注明；
- 没开“定时复盘”：盘后同步的时间再过 10 分钟就发。

飞书没发出去时，同一天最多试 3 次。

## 网页里有什么

面板几个页面当时的样子，各截一张长图，直接嵌在网页文件里：看板、连板梯队、概念板块、行业板块、市场环境、每日复盘（首页和当天全文）。

- 截图由面板自己在后台开一个不显示窗口的浏览器完成（`shots.py`），只访问本机的面板，不需要 AI，也不联网。
- 用的是这台电脑上已有的 Chrome/Chromium（自动找，也可以在设置文件里用 `browser` 指定）；一次大约两分钟。
- 面板跑在 Windows 的 Linux 子系统里时，Linux 这边没有中文字体，这里只给这个浏览器进程指向 Windows 自带的微软雅黑，不改系统设置。
- 找不到浏览器、或者一张都没截下来时，网页退回文字版：定时任务情况、市场快照、持仓、当天的监控信号、复盘全文。

邮件正文只有几行：指数涨跌、涨跌家数和成交额、持仓市值和盈亏，其余看附件。

网页存在 `data/user_data/extensions/daily_digest/pages/日期.html`（保留最近 90 份，每份约 5MB），只在本机，不上传。

## 飞书

- **摘要卡片**（可在“设置 → 每日汇总”里关掉，关掉后只发邮件）：用“监控中心”里配好的那个飞书群机器人发。这种机器人不能发文件，卡片里放的是摘要、复盘全文和一个指向本机的链接。
- **网页文件（可选）**：在“设置 → 每日汇总”里填一个飞书自建应用的 App ID 和 App Secret 后，网页会作为 `日期 每日汇总.html`
  文件先发进群，手机和电脑都能打开。应用要有机器人能力和三项权限（`im:message:send_as_bot`、`im:resource`、`im:chat:readonly`），
  并且机器人已经加进要接收的群。一次发送 3 个请求（登录、上传、发消息），只发往飞书开放平台。
  文件没发出去时卡片照常发，原因写在卡片里。密钥存在面板的 `secrets.json`，不进设置文件。

- **邮件（推荐）**：“设置 → 实时监控”里配好邮箱后，网页会发成一封邮件：正文就是网页，另带一个 HTML 附件，手机和电脑都能打开。
  这台电脑只能经代理上网，邮件经本机代理的隧道连到邮件服务器（见 `app/services/email_adapter.py`）。

## 设置和接口

`data/user_data/extensions/daily_digest/config.json`（没有就用默认值）：`{"enabled": true, "feishu_card": true, "screenshots": true, "panel_url": "http://127.0.0.1:3011", "browser": "", "base_url": "http://localhost:3018"}`。

- `GET /api/custom/daily-digest/status`：设置、今天发过没有、已有哪些天的网页
- `GET /api/custom/daily-digest/page/日期`（或 `latest`）：打开网页
- `PUT /api/custom/daily-digest/app`、`DELETE /api/custom/daily-digest/app`：保存（并当场验证）或删除自建应用的设置
- `POST /api/custom/daily-digest/run?send=true`：现在就生成一份；带 `send=true` 时同时推到飞书（不影响当天的自动推送）
