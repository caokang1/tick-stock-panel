# 期货行情

左侧菜单“期货”页面的后端。只展示行情，不参与选股、回测和提醒。

## 看什么

| 分组 | 品种 |
| --- | --- |
| 股指期货 | 沪深 300、上证 50、中证 500、中证 1000 的主力连续，带现货指数和升贴水 |
| 贵金属和有色 | 沪金、沪银、沪铜 |
| 能源、黑色和国债 | 原油、螺纹钢、10 年期国债 |
| 外盘 | 伦敦金、伦敦银、纽约黄金、纽约白银、纽约铜、纽约原油 |

要增减品种，改 `catalog.py` 里的清单。

## 数据从哪来

新浪财经的公开行情接口。所有品种和四个现货指数一次请求取回；日线按品种取，点开哪个取哪个。

- 每个请求都经过免费数据源的限流器，和分钟 K 共用新浪这一路的计数（排队一个一个发，被拒绝后自动暂停）。
- 跟着面板的“实时行情”开关走：开关开着才联网取，关着时一个请求都不发，页面上是上一次取到并存在本机的数据。
- 更新间隔用的是“通达信公式 → 数据”里“每隔多少秒取一轮全市场快照”那个设置，和股票行情一致；日线也按这个间隔，点开哪个品种取哪个。
- 页面开着才会取，关掉页面就不取。取到的数据存在 `data/user_data/extensions/futures/`。
- 国内期货的涨跌按昨结算价计算，和交易所口径一致；外盘按接口给的昨结算。
- 升贴水 = 期货主力连续的最新价 − 现货指数最新价。

## 接口

- `GET /api/custom/futures/quotes` 所有品种的最新行情
- `GET /api/custom/futures/kline?code=AU0` 一个品种最近 180 根日线
